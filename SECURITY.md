# Security Policy

## Supported versions

Security fixes are provided for the latest release.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature when it is available.
If it is not available, open an issue that asks the maintainer for a private
contact channel without posting exploit details.

Do not include credentials, private directory contents, complete logs, or other
personal data in a report. A minimal synthetic configuration is preferred.

Security-sensitive areas include path-containment bypasses, unsafe deletion,
junction confusion, rollback failure, and copying through unexpected reparse
points.
